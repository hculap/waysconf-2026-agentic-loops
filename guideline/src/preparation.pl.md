# Przygotowanie

## Wymagania

- Laptop z macOS, Windows albo Linuksem, na którym możesz instalować oprogramowanie. Jeśli nie możesz, użyj GitHub Codespace. Opis znajdziesz na końcu strony.
- Płatna subskrypcja **Claude Pro lub Max** albo **ChatGPT Plus**. Darmowe plany nie obejmują agentów w terminalu.
- Umiejętność programowania nie jest potrzebna.

---

## Czego dotyczy warsztat

::diagram:01-the-loop::

Agent buduje stronę na podstawie projektu z Figmy. Osobny program, który agent też pisze,
porównuje stronę z projektem i zgłasza każdą różnicę. Agent poprawia zgłoszone błędy
i uruchamia program ponownie, aż wszystkie testy przejdą. Na końcu strona trafia na Netlify.

## Otwórz terminal

Terminal to okno, w którym uruchamiasz programy, wpisując komendy. Każda komenda na tej
stronie ma przycisk **Kopiuj**: kopiujesz ją, wklejasz do terminala i naciskasz Enter, a
następną uruchamiasz dopiero wtedy, gdy wróci znak zachęty.

## Zainstaluj narzędzia

|---|---|
