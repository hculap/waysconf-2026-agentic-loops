# Preparation

## Requirements

- A laptop with macOS, Windows or Linux on which you can install software. If you cannot install software, use a GitHub Codespace instead, as described at the end of this page.
- A paid **Claude Pro or Max** or **ChatGPT Plus** subscription. The free plans do not include the command-line agents.
- No programming experience is required.

---

## What the workshop covers

::diagram:01-the-loop::

A coding agent builds a page from the Figma design. A separate program, which the agent also
writes, checks the page against the design and reports every difference. The agent fixes the
reported problems and runs the program again until it passes. The page is then published on
Netlify.

## Open a terminal

A terminal is a window for running programs by typing commands. Every command on this page
has a **Copy** button: copy the command, paste it into the terminal, press Enter, and wait for
the prompt to return before running the next one.

| Tool | Purpose |
|---|---|

| Netlify CLI | publishes the site |
