# Before you come

About thirty minutes, top to bottom: four accounts, a few tools, signing in, your own
repository — and at the end your agent checks the lot and tells you what is missing. Do it
at home. The room has thirty people and one wifi network, and an installer is a miserable
way to spend the first twenty minutes of a workshop.

**You do not need to know how to code.** This session is built for designers and product
people. Every command on this page has a copy button: copy, paste into the terminal, press
Enter, and wait for it to finish before the next one.

---

## What we are going to build

::diagram:01-the-loop::

An agent writes a page. A **program** — not the agent — checks it against the design, the
contrast rules and the copy, and writes down what is wrong. The agent reads that and fixes
it. Round and round until the program says nothing is wrong, and then it goes live.

The interesting box is the one that refuses. Everything below is what you need so you can
build one of those on Wednesday.

## Open a terminal

If you have never opened one, this is the part that stops people, and it stops them before
they have started. It is two steps and it is not dangerous.

A terminal is a window where you type the name of a program, press Enter, and it prints the
answer back as text. `npm install` and a button labelled **Install** do the same work — one
is addressed by name, the other by clicking.

## Install the tools

**Netlify command line**, which publishes the site. Copy each command, paste it into the

## On the day

**Bring:** your laptop, your charger, and headphones if you like working with them.

**Arrive:** fifteen minutes early if your agent did not say READY.

**You will leave with:** a live address, your repository with the code in it, a page of
prompts you can reuse on Monday, and a fairly specific opinion about when to trust a
language model.
