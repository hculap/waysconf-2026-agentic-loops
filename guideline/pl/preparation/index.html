Przygotowanie

Wykonaj te kroki przed 16 września, na komputerze, który przyniesiesz na warsztat. Zajmie to około 30 minut.

Ostatni krok to prompt: agent sprawdza konfigurację i wypisuje, czego brakuje.

Wymagania

  • Laptop z macOS, Windows albo Linuksem, na którym możesz instalować oprogramowanie. Jeśli nie możesz, użyj GitHub Codespace. Opis znajdziesz na końcu strony.
  • Płatna subskrypcja Claude Pro lub Max albo ChatGPT Plus. Darmowe plany nie obejmują agentów w terminalu.
  • Umiejętność programowania nie jest potrzebna.

Czego dotyczy warsztat

Agent buduje stronę na podstawie projektu z Figmy. Osobny program, który agent też pisze, porównuje stronę z projektem i zgłasza każdą różnicę. Agent poprawia zgłoszone błędy i uruchamia program ponownie, aż wszystkie testy przejdą. Na końcu strona trafia na Netlify.

System operacyjny

System operacyjny

Instrukcje poniżej dopasują się do wyboru.

Otwórz terminal

Terminal to okno, w którym uruchamiasz programy, wpisując komendy. Każda komenda na tej stronie ma przycisk Kopiuj: kopiujesz ją, wklejasz do terminala i naciskasz Enter, a następną uruchamiasz dopiero wtedy, gdy wróci znak zachęty.

macOS

  1. Naciśnij Cmd + Spacja.
  2. Wpisz Terminal.
  3. Naciśnij Enter.

Wklejanie: Cmd + V.

Windows

  1. Naciśnij klawisz Windows.
  2. Wpisz PowerShell.
  3. Kliknij Windows PowerShell. Nie używaj Wiersza polecenia.

Wklejanie: Ctrl + V albo prawy przycisk myszy.

Linux

  1. Naciśnij Ctrl + Alt + T.
  2. Jeśli okno się nie otworzy, wyszukaj Terminal w menu aplikacji.

Wklejanie: Ctrl + Shift + V. Samo Ctrl + V w terminalu nie wkleja.

Jak działa terminal

Znak zachęty: linijka z kursorem, zakończona na $, % albo >. Terminal czeka na komendę.
Uruchomienie komendy: wklej ją i naciśnij Enter.
Brak komunikatów: niektóre komendy przez minutę albo dłużej nic nie wypisują. Nadal działają.
Koniec: komenda skończyła działanie, kiedy znów pojawi się znak zachęty.
Wcześniejsze linijki: nie da się ich edytować. Wpisywać można tylko w bieżącej.
Komendy na tej stronie: instalują narzędzia, logują cię, zakładają repozytorium albo wypisują status.

Node, Git i GitHub CLI na macOS

brew install node gh

Wymaga Homebrew. Jeśli go nie masz, najpierw uruchom komendę instalacyjną ze strony brew.sh. Zapyta o hasło do Maca, a wpisywane znaki nie będą widoczne. Homebrew instaluje też Gita. Na koniec zamknij terminal i otwórz nowy.

Node, Git i GitHub CLI na Windows

winget install --id OpenJS.NodeJS.LTS
winget install --id Git.Git
winget install --id GitHub.cli
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Uruchamiaj komendy po jednej. Ostatnia pozwala PowerShellowi uruchamiać npm i agenta. Bez niej pojawi się błąd running scripts is disabled on this system. Jeśli padnie pytanie, wpisz Y i naciśnij Enter. Na koniec zamknij PowerShell i otwórz nowy.

Node, Git i GitHub CLI na Linuksie

sudo apt install -y curl git gh
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.7/install.sh | bash
nvm install --lts

Pierwsza komenda zapyta o hasło, a wpisywane znaki nie będą widoczne. Przed trzecią komendą zamknij terminal i otwórz nowy. Node instalujemy przez nvm, bo paczki z dystrybucji bywają starsze niż wymagana wersja 22.15. Dzięki temu instalacja przez npm nie wymaga też sudo. Inne dystrybucje: zainstaluj curl, git i gh swoim menedżerem paczek (instrukcja dla gh).

Przeglądarka dla checkera

Checker, który zbudujesz na warsztacie, otwiera stronę w Chromium przez Playwright. Pobranie go teraz oszczędza około 150 MB na konferencyjnym wifi. Na Linuksie, jeśli zgłosi brak bibliotek, uruchom zamiast tego npx playwright install --with-deps chromium; zapyta o hasło.

npx playwright install chromium

Jeśli komenda zaraz po instalacji zwraca command not found, zamknij terminal i otwórz nowy.

Zaloguj się

Każda komenda logowania otwiera przeglądarkę. Tam zatwierdzasz dostęp i wracasz do terminala. Komenda statusu potwierdza wynik.

GitHub

gh auth login

Odpowiadaj strzałkami i klawiszem Enter: GitHub.com → HTTPS → Yes (logowanie Gita) → Login with a web browser. Skopiuj jednorazowy kod i naciśnij Enter. W przeglądarce wklej kod i kliknij Authorize.

Sprawdź:

gh auth status
Logged in to github.com

Agent do kodu

Claude Pro lub Max

claude auth login

Zaloguj się na claude.ai w przeglądarce i kliknij Authorize. Jeśli terminal poprosi o kod, skopiuj go z przeglądarki i wklej.

Sprawdź:

claude auth status
"loggedIn": true

ChatGPT Plus

codex login

Zaloguj się do ChatGPT w przeglądarce i zezwól na dostęp. Terminal potwierdzi zakończenie logowania.

Sprawdź:

codex login status
Logged in using ChatGPT

Netlify

netlify login

Kliknij Authorize w przeglądarce i wróć do terminala.

Sprawdź:

Załóż repozytorium

Ta komenda zakłada na twoim koncie GitHub prywatne repozytorium turbine. Klonuje je też do folderu turbine w bieżącym katalogu.

gh repo create turbine --private --clone
cd turbine

Warsztat zaczyna się w tym folderze: cd turbine, potem uruchom agenta. Nie dodawaj do niego plików.

Sprawdź:

git remote -v
github.com/twoja-nazwa/turbine

Jeśli masz już repozytorium o nazwie turbine, wybierz inną nazwę. Używaj jej wszędzie tam, gdzie ta strona pisze turbine.

Sprawdź konfigurację

Agent sprawdza wszystko z poprzednich kroków i wypisuje, czego brakuje. Niczego nie zmienia.

  1. Przejdź do folderu projektu:
    cd turbine
  2. Uruchom agenta: claude albo codex. Jeśli zapyta, czy ufasz temu folderowi, odpowiedz tak.
  3. Wklej prompt poniżej i naciśnij Enter.
Wklej to agentowi 
Sprawdź, czy ten komputer jest gotowy do warsztatu. Niczego nie instaluj, nie loguj się
i niczego nie zmieniaj: tylko sprawdzaj i uruchamiaj takie komendy, jakich do tego potrzebujesz.

Sprawdź każdy punkt i podaj wynik w tabeli z trzema kolumnami: co sprawdziłeś, co znalazłeś,
OK albo NIE OK.

1. Node jest zainstalowany, w wersji 22.15 lub nowszej, i npm działa.
2. Git jest zainstalowany i ma ustawione imię oraz adres e-mail.
3. GitHub CLI (gh) jest zainstalowane i zalogowane.
4. Netlify CLI jest zainstalowane i zalogowane.
5. Ty, agent, który robi to sprawdzenie, jesteś zainstalowany i zalogowany. Napisz, którym
   agentem jesteś.
6. Ten folder jest repozytorium git z remote na GitHubie, a to repozytorium istnieje na
   koncie, na które zalogowane jest gh.
7. W tym folderze nie ma nic poza plikami samego gita.
8. Przeglądarka Chromium dla Playwright jest już pobrana (sprawdź w katalogu przeglądarek
   Playwright; nie pobieraj jej sam).

Dla każdego punktu NIE OK podaj poprawkę w jednym lub dwóch prostych zdaniach, z dokładną
komendą, jeśli taka jest. Zakończ jedną linijką: GOTOWE albo NIEGOTOWE i liczba punktów
do poprawienia.

Przed każdą komendą agent pyta o zgodę. Zgódź się. Popraw każdy punkt NIE OK i uruchom ten sam prompt jeszcze raz, aż wynik będzie GOTOWE. Jeśli agent się nie uruchamia, powtórz krok Zaloguj się.

Bez instalacji: GitHub Codespaces

Jeśli nie możesz instalować oprogramowania, użyj GitHub Codespace. To komputer w chmurze, dostępny w przeglądarce. Ma zainstalowane Node, Gita i GitHub CLI, zalogowane do GitHuba.

  1. Na github.com kliknij + → New repository. Nazwa: turbine. Widoczność: Private. Zaznacz Add a README file, bo dla pustego repozytorium nie da się utworzyć Codespace. Kliknij Create repository.
  2. Na stronie repozytorium kliknij Code → Codespaces → Create codespace on main. Terminal to panel na dole, otwarty w folderze repozytorium.
  3. Usuń README, żeby folder był pusty:
    rm README.md
  4. Zainstaluj agenta i Netlify CLI komendami z sekcji Zainstaluj narzędzia. Przeglądarkę zainstaluj przez npx playwright install --with-deps chromium. Node, Git i GitHub CLI są już zainstalowane.
  5. Zaloguj się do agenta i do Netlify zgodnie z sekcją Zaloguj się. Zamiast otwierać przeglądarkę, terminal wypisze link. Przytrzymaj Ctrl albo Cmd i kliknij go. W Codeksie użyj logowania kodem urządzenia:
    codex login --device-auth

    Jeśli Codex zgłosi, że logowanie kodem urządzenia jest wyłączone, włącz je w ChatGPT → Settings → Security i uruchom komendę ponownie.

  6. Wykonaj krok Sprawdź konfigurację w terminalu Codespace. Pomiń cd turbine, bo terminal jest już w folderze projektu.

Darmowy plan GitHuba obejmuje 120 rdzeniogodzin Codespaces miesięcznie. Warsztat zużywa około 3. W dniu warsztatu otwórz ten sam Codespace z github.com/codespaces.

Pytania

Czy muszę umieć programować?

Nie. Opisujesz problemy zwykłym językiem, a kod pisze agent.

Czy wystarczy darmowy plan AI?

Nie. Darmowe plany Claude i ChatGPT nie obejmują Claude Code ani Codeksa. Wystarczy najtańszy płatny plan jednego z nich.

Po co repozytorium na GitHubie?

Przechowuje projekt. Po warsztacie zostaje ci kod.

Czy potrzebuję konta w Figmie?

Nie. Plik projektu pobierasz ze strony warsztatu. Darmowe konto w Figmie pozwala tylko oglądać projekt w Figmie.

Sprawdzenie zwraca NIE OK i nie wiem dlaczego.

Poproś agenta, żeby wyjaśnił ten punkt krok po kroku. Jeśli problem zostanie, przyjdź 15 minut przed startem warsztatu.

Czy w trakcie warsztatu potrzebny jest internet?

Tak. Na sali jest wifi. Agent instaluje paczki, dekoduje plik Figmy i publikuje stronę.

Nie mogę instalować programów na laptopie.

Użyj Codespace. Opis jest w sekcji o pracy bez instalacji.

Czy to działa na Windows?

Tak. Używaj PowerShella, nie Wiersza polecenia.

Co zostaje mi po warsztacie?

Opublikowana strona, repozytorium z kodem i prompty.

W dniu warsztatu

  • Weź laptop i ładowarkę.
  • Jeśli sprawdzenie nie zakończyło się wynikiem GOTOWE, przyjdź 15 minut przed startem.
