Zanim przyjdziesz

Dziewięćdziesiąt minut, trzydzieści osób, jedna pętla. Agent dostaje design, pisze stronę, a potem program — nie on sam — mówi mu wszystko, co jest z nią nie tak. Agent to poprawia i słyszy to jeszcze raz.

Ta strona to przygotowanie. Zajmuje jakieś piętnaście minut i idzie dużo lepiej w domu niż na konferencyjnym wifi.

Piętnaście minut, cztery darmowe konta, jedna instalacja. Zrób to w domu — na sali będzie trzydzieści osób i jedno wifi, a formularze rejestracji to marny sposób na spędzenie pierwszych dwudziestu minut warsztatu.

Nie musisz umieć programować. Ta sesja jest zrobiona dla projektantów i ludzi od produktu. Wpiszesz kilka komend i powiesz dużo rzeczy po ludzku.

Co będziemy budować

Agent pisze stronę. Program — nie agent — sprawdza ją względem designu, reguł kontrastu i tekstów, po czym spisuje, co jest nie tak. Agent to czyta i poprawia. I w kółko, aż program nie ma już nic do powiedzenia, a wtedy strona idzie na serwer.

Ciekawe jest to pudełko, które odmawia. Wszystko poniżej to rzeczy, które trzeba mieć zainstalowane, żeby w środę zbudować taką pętlę samodzielnie.

Jak otworzyć terminal

Jeśli nigdy go nie otwierałeś, to jest ten moment, w którym ludzie odpadają — i odpadają, zanim w ogóle zaczną. To dwa kroki i nie jest niebezpieczne.

Terminal to okno, w którym wpisujesz nazwę programu, naciskasz Enter, a on wypisuje odpowiedź jako tekst. npm install i przycisk z napisem Instaluj robią dokładnie to samo — jedno wywołujesz nazwą, drugie kliknięciem.

Jak otworzyć terminal na macOS

  1. Naciśnij Cmd + Spacja.
  2. Wpisz Terminal.
  3. Naciśnij Enter.

Otworzy się okno z linijką tekstu i migającym kursorem. To wszystko. Wklejasz do niego przez Cmd + V.

Jak otworzyć terminal na Windows

  1. Naciśnij klawisz Windows.
  2. Wpisz PowerShell.
  3. Kliknij Windows PowerShell — nie „Wiersz polecenia", który wygląda podobnie i zachowuje się inaczej.

Otworzy się niebieskie okno z linijką tekstu i migającym kursorem. To wszystko. Wklejasz przez Ctrl + V albo prawym przyciskiem myszy.

Jak otworzyć terminal na Linuksie

  1. Naciśnij Ctrl + Alt + T.
  2. Jeśli nic się nie stanie, otwórz menu aplikacji i poszukaj Terminal.

Wklejasz przez Ctrl + Shift + V — samo Ctrl + V znaczy w terminalu coś innego.

Sześć rzeczy, których nikt nie mówi

Linijka z kursorem to prompt. Kończy się na $, % albo > i oznacza, że terminal czeka na ciebie.
Wklej, potem naciśnij Enter. Nic się nie uruchomi, dopóki tego nie zrobisz.
Cisza jest normalna. Komenda potrafi stać przez minutę i nic nie wypisywać. Nie zawiesiła się — pracuje. Nauczysz się czekać.
Skończyła się, kiedy wraca prompt. To jedyny sygnał, jaki dostajesz.
To, co przewinęło się do góry, jest zapisem. Nie da się kliknąć w starą linijkę i jej poprawić. Żyje tylko ta, którą właśnie piszesz.
Niczym z tej strony nie zepsujesz komputera. Każda komenda tutaj albo coś instaluje, albo wypisuje numer wersji.

Zainstaluj jedną rzecz

Potrzebujesz Node na swoim komputerze, a potem jednego z dwóch agentów terminalowych — tego, który pasuje do subskrypcji, którą już masz. Skopiuj każdą komendę, wklej do terminala, który przed chwilą otworzyłeś, naciśnij Enter i poczekaj, aż wróci prompt, zanim przejdziesz do następnej.

Node, na macOS

brew install node

Nie masz Homebrew? Pobierz instalator LTS z nodejs.org, otwórz i przeklikaj. Potem zamknij terminal i otwórz nowy.

Node, na Windows

winget install OpenJS.NodeJS.LTS

Albo instalator z nodejs.org. Tak czy inaczej zamknij potem PowerShell i otwórz nowy — nowe programy zauważa tylko przy starcie.

Node, na Linuksie

sudo apt install -y nodejs npm

Zapyta o hasło; przy wpisywaniu nic się nie pokazuje i tak ma być. Potrzebny jest Node 20.11 albo nowszy — jeśli twoja dystrybucja ma starszy, użyj nvm.

Potem jeden agent — ten, za którego już płacisz

Potrzebujesz jednego z tych dwóch, nie obu. Masz subskrypcję Claude — bierz pierwszy. Masz ChatGPT Plus — drugi.

Claude Pro albo Max

npm install -g @anthropic-ai/claude-code

ChatGPT Plus

npm install -g @openai/codex

Czy jestem gotowy?

Uruchom te cztery w terminalu. Pierwsze dwie muszą wypisać numer wersji; z dwóch ostatnich tylko ta, którą zainstalowałeś.

node -v
wypisze v20.11.0 albo wyżej
npm -v
wypisze dowolną wersję
claude --version
tylko jeśli wybrałeś Claude
codex --version
tylko jeśli wybrałeś ChatGPT

Jeśli któraś mówi command not found, to znaczy, że tej rzeczy nie ma. Wróć krok wstecz — albo przyjdź piętnaście minut wcześniej na salę, ktoś to z tobą ogarnie.

Jeśli instalacja nie wchodzi w grę

Część służbowych laptopów nie pozwoli zainstalować niczego i to jest w porządku.

Otwórz repozytorium warsztatu na GitHubie, kliknij zielony przycisk Code, wybierz Codespaces i utwórz jeden. Dostajesz pełną maszynę w przeglądarce, z Node i oboma agentami już na pokładzie. Zrób w niej pusty folder i zacznij tam — sam warsztat nigdy nie dotyka zawartości repozytorium.

Darmowy plan GitHuba obejmuje 120 rdzeniogodzin miesięcznie. Ta sesja zużywa jakieś dwie.

Pytania, które ludzie zadają

Nigdy nie używałem terminala.

Dobrze — jedna trzecia sali też nie. Jest o tym osobna sekcja wyżej, a pierwsze, o co poprosisz agenta, to żeby tłumaczył każdą komendę na bieżąco.

Czy muszę umieć programować?

Nie. Będziesz czytać kod i mówić po ludzku, co jest nie tak z wynikiem. Dokładnie o tej robocie jest ta sesja.

Nie chcę płacić za subskrypcję AI.

Darmowe plany obu produktów nie obejmują narzędzia w terminalu, więc na darmowym koncie pętla nie ruszy. Najtańszy plan któregokolwiek wystarczy, a potem można zrezygnować.

Mam darmową Figmę.

To bezpośrednie połączenie Figma–agent odmówi i nic poza tym się nie zmienia. Zapisujesz plik z Figmy — dwa kliknięcia — i dajesz go agentowi.

Czy na warsztacie będę potrzebować internetu?

Tak, i na sali on jest. Agent instaluje paczki, rozkodowuje plik Figmy i publikuje twoją stronę — wszystko to idzie przez sieć. Jeśli Codex zapyta o dostęp do sieci, odpowiedz tak.

Służbowy laptop nie pozwala mi nic instalować.

Skorzystaj z wersji w przeglądarce. Dostajesz gotową maszynę ze wszystkim i nie instalujesz niczego.

Czy to zadziała na Windows?

Tak. Używaj PowerShella, nie starego Wiersza polecenia. Reszta sesji jest identyczna.

A jeśli zostanę w tyle?

Nie da się — nie w sposób, który ma znaczenie. Każdy prompt stoi sam: jeśli któryś idzie źle, powiedz agentowi, żeby przestał, i wklej następny. Wpół zbudowana strona z działającym checkerem uczy więcej niż skończona bez niego.

Co zabieram do domu?

Działający adres URL, stronę z promptami i design. Wszystko zostaje online po konferencji.

W dniu warsztatu

Weź ze sobą: laptopa, ładowarkę i słuchawki, jeśli lubisz przy nich pracować.

Przyjdź: kilka minut wcześniej, jeśli cokolwiek z powyższych nie zadziałało.

Wyjdziesz z: działającym adresem w internecie, stroną promptów, których użyjesz w poniedziałek, i dość konkretnym zdaniem na temat tego, kiedy ufać modelowi językowemu.
